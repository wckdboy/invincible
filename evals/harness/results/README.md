# Recorded runs

One directory per date, with the reports from `evals/harness/run.py` and a short summary. The
reports are snapshots: models, versions and machine load change, so rerun the suite rather than
comparing a new number with an old one.

The raw per-run logs and final project trees stay in `evals/harness/runs/` (ignored); these
directories keep the results without the megabytes.
